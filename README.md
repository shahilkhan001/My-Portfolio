# Developer Portfolio

Personal developer portfolio showcasing Android, full-stack, and software development projects built using React.js and Tailwind CSS.

## Features

* Responsive modern UI
* Project showcase section
* Skills and technology stack overview
* Contact and social links integration
* Mobile-first responsive design
* Smooth scrolling and interactive navigation

## Tech Stack

* React.js
* Tailwind CSS
* JavaScript
* HTML5
* CSS3

## Featured Projects

* Bharat Bhraman – AI-powered tourism Android application
* Tourist Safety Application – Real-time safety platform
* GeoAI Smart Explorer – Android app with Google Maps API integration
* Fitzon Fitness – Responsive fitness website

https://shahilkhan-dev.vercel.app

## Installation

1. Clone the repository
2. Install dependencies using `npm install`
3. Start the development server using `npm start`
